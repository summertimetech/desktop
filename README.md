# MS Digital Sovereignty   

Most MS Windows 11 users are aware that a lot of their personal data is send to Microsoft servers.  
Some of it can be a good thing like having files copied to a backup. 
But a lot of user data send to Microsoft servers can be qualified as "spying on users".  
Striving for digital sovereignty Linux Mint is a great alternative.
